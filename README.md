# Dental Care Center

A modern, responsive dental clinic website built using React, TypeScript, Vite, Tailwind CSS, Node.js, Express.js, and MySQL/MariaDB.

## Project Structure

- `frontend/` — React website and Admin Panel.
- `backend/` — Node.js and Express API.
- `database/schema.sql` — Database schema.
- `database/migrations/` — Database migrations.
- `reference-assets/` — Project reference assets.

## Features

- Responsive dental clinic website.
- Dentist profiles and interactive doctor cards.
- Appointment booking.
- Services and gallery management.
- Admin authentication.
- Patient management.
- Prescription creation and history.
- Medicine catalogue and suggestions.
- Prescription printing and PDF download.
- MySQL/MariaDB database integration.

## Technology Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS.
- Backend: Node.js and Express.js.
- Database: MySQL/MariaDB.
- Version Control: Git and GitHub.
